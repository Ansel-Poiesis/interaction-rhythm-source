# Security policy

Please report security vulnerabilities through [GitHub's private vulnerability reporting form](https://github.com/Ansel-Poiesis/interaction-rhythm-source/security/advisories/new). Do not post credentials, personal data, or an exploitable proof of concept in a public issue.

For ordinary reproducible defects, use the public [bug-reporting guide](docs/bug-reporting.md) and its issue template. Do not attach databases, diagnostic logs, screenshots, exports, API keys, or personal activity data.

The report should describe the affected version, impact, and a minimal reproduction. The maintainer will coordinate disclosure and a fix through the private report where possible. There is no guaranteed response time or security support contract.

The project is a local Windows desktop application. Review the [data and privacy notes](docs/data-and-privacy.md) when reporting issues involving collection, local storage, AI providers, or email delivery.
