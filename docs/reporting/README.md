# Public reporting contracts

The JSON schema, method library, and source index are the public contracts used by the optional local report-evidence pipeline.

- report-evidence.schema.json defines the evidence packet structure.
- method-library.json contains project-authored analysis and writing heuristics. These are product rules, not independently validated scientific findings.
- research-index.json lists public references used for terminology or statistical methods. A reference does not establish that the app's metrics diagnose attention, productivity, health, or intent.

Private project research notes, local evidence, personal samples, and internal paths are not part of this source release.
