# 使用指南

本指南对应公开软件版本 `v0.1.0 / epoch 2`。它是 Windows 桌面应用的使用说明；本次公开仅提供源码，没有对应的 Windows 安装包。

## 使用前了解

扣舷-数字节律以本机方式记录数字设备使用节律。应用运行时统计键盘输入事件数、鼠标点击和滚轮事件数，并记录前台应用进程名、可执行文件路径、停留区间与采集健康状态。它不读取键入字符、窗口标题、浏览器页面内容、鼠标坐标或屏幕画面。

启动应用会开始本机采集。数据默认保存在应用数据目录；从源码运行时默认位于仓库的 `data/`。具体数据边界和可选云端功能见[数据与隐私说明](data-and-privacy.md)。

## 环境与启动

源码运行需要 Windows 10 或 11、Python 3.10 或更新版本，以及 Microsoft Edge WebView2 Runtime。完整的隔离环境创建步骤见[源码运行指南](building-from-source.md)。

在仓库根目录运行：

```powershell
python main.py
```

桌面窗口关闭按钮会将窗口隐藏到系统托盘，应用和采集仍继续运行。右键托盘图标可以打开应用、刷新数据或选择“退出后台”完全退出。

首次尝试时可将开发数据目录指向临时位置，避免与已有本机数据混用：

```powershell
$env:INTERACTION_RHYTHM_DATA_DIR = Join-Path $env:TEMP 'digital-rhythm-dev-data'
python main.py
```

## 查看数字手感

主面板顶部的日期按钮选择查看日期，左右箭头切换前后日期，点击日期可回到今天。指标卡显示键盘、点击、滚轮及前台停留时间的汇总。

热力图可分别开启或隐藏键盘、鼠标两类事件，并切换周、月、年范围。周期箭头用于前后移动。采集覆盖不足或应用尚未运行时，热力图和榜单可能显示为空；这表示缺少本机记录，不是零强度结论。

“应用强度榜”按本机记录的前台应用和活动分布汇总。它不读取应用窗口内容，也不判断工作质量。页面上的数字用于回看节律，不构成效率、健康或人格评分。

## 导出数据

1. 打开右上角“设置”。
2. 在“数据与版本”中选择“导出数据”。
3. 选择 JSON 或 CSV。导出范围为最近 30 天；JSON 保留完整数据结构，CSV 适合在表格软件中查看。

导出文件可能包含应用名称和本机活动统计。分享或交给外部服务前，先检查文件内容并确认接收方。

## 可选 AI 回放

如果希望直接在应用中使用 AI：

1. 在“设置”中的“AI 建议”选择服务并填写 API Key。
2. 使用“查看出站字段”先预览将发送和不会发送的字段。
3. 回到主面板打开“手感回放”查看建议。

API Key 保存在本机设置中。只有配置服务并主动请求分析时，应用才会把获准的聚合数据发送到所选提供方。聚合内容可能包括前台应用名称、活动统计、时间分布、个人参照、覆盖情况、已审阅的理论卡片和你输入的修正或提示词；不包括键入字符、原始输入事件、可执行文件路径、鼠标坐标、截图、窗口标题或浏览器页面内容。所选服务自己的条款和数据保留政策适用。

未配置 API Key 时，应用可导出最近 30 天 JSON，并提供可复制的提示词。你可以自行决定是否把数据交给任何外部 AI；数据离开本机后的处理由该服务负责。

## 可选邮件报告

邮件功能需要你在设置中配置 SMTP 或 QQ Agent Mail、验证收件邮箱，并主动选择周报或月报订阅。发送前可以预览完整邮件，并在发送界面确认。

邮件报告包含日期、键盘/鼠标汇总、前台时长、覆盖情况和观察时段边界，不包含单个应用名称、可执行文件路径、窗口标题或原始事件记录。订阅时间按本机时间运行；关闭应用期间的到期报告会在下次启动时补发。你可以随时取消订阅或退出邮箱登录。

## 备份、隐私和退出

- 在“设置”中的“数据与版本”查看本机数据目录、导出数据、创建和管理备份。恢复备份会覆盖当前数据；确认选择的备份文件后再执行。
- 从旧版本导入的数据库可能保留历史窗口标题值。使用同一区域的“清除历史窗口标题”操作清理这些旧值；新采集不会写入窗口标题。
- “隐私”区域可配置隐藏应用列表。隐藏的应用仍参与统计，但名称不会显示在榜单和详情中；该设置不会删除本地原始记录。
- 完全停止后台采集时，右键系统托盘图标并选择“退出后台”。仅关闭窗口不会停止采集。

有关采集字段、存储位置、云端发送和用户控制的完整说明，请阅读[数据与隐私说明](data-and-privacy.md)。遇到缺陷时请按[缺陷报告指南](bug-reporting.md)提交；不要在公开 Issue 中附上数据库、日志、导出文件、邮箱或密钥。
