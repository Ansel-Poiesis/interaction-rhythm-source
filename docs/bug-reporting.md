# 缺陷报告指南

请先在[公开 Issue 列表](https://github.com/Ansel-Poiesis/interaction-rhythm-source/issues)搜索相同问题，再新建 Issue。仓库提供的 Bug report 模板会收集复现问题所需的最少信息。

请尽量提供：

- 应用版本与 Windows 版本。
- 发生问题前的操作步骤，以及预期结果和实际结果。
- 问题是否每次出现；可复现时提供最短步骤。
- 不含私人记录的错误提示或合成示例。

## 保护本机数据

不要把数据库、日志、诊断文件、截图、导出文件、邮箱地址、API Key、OAuth 内容、收件人信息或其他个人数据附加到公开 Issue。请先检查复制的错误信息，移除路径、账户名、收件人和令牌。

如果怀疑安全漏洞，请勿公开描述可利用细节。请使用 [GitHub 私密漏洞报告](https://github.com/Ansel-Poiesis/interaction-rhythm-source/security/advisories/new)。私密报告和普通功能缺陷使用不同通道。

请按[贡献指南](../CONTRIBUTING.md)说明复现环境与验证命令。项目会在公共 Issue 中保留报告和后续讨论，方便其他用户搜索。
