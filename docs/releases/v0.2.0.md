# v0.2.0 — 扣舷-数字节律公开源码版本

- 日期：2026-11-27
- 作者：Ansel · [keeppoiesis.com](https://keeppoiesis.com/)
- 许可证：MIT（第三方字体和可选组件仍遵循各自许可证）

## 主要更新

- **大库日期切换与热力图后端优化（`db.py`）**
  - 新增 3 个幂等辅助索引（`idx_app_usage_end_start`、`idx_fg_ended_started`、`idx_obs_comp_ended_started`），不改表结构且保持 `schema_version = 2`；主连接与工作线程连接统一启用 `PRAGMA busy_timeout=5000`。
  - `_hourly_table`、`app_chart`、`hour_detail`、`daily_summary`、`app_detail` 改用等价时间范围谓词命中时间索引；合并 `day_stats` 与 `day_metrics` 中的重复扫描；`_app_usage_for_day` 分离开放会话（`end IS NULL`）分支并按首末索引 O(1) 择优与稳定排序。
  - `month_heatmap`、`year_heatmap` 与 `daily_keystrokes` 改用单次范围扫描叠加内存归档补齐，消除 `NOT EXISTS` 关联子查询与 12 次月循环全扫。
  - 新增 `tests/test_date_query_optimization.py` 回归测试（含 `EXPLAIN QUERY PLAN` 防退化断言）。
- **前端渐进式日期切换与防竞态（`static/app.js`）**
  - 今日汇总、6 日热力图与应用强度榜各自独立请求和渲染，主面板不再等待 `/api/agent/observations`。
  - 增加 12 日期内存缓存、相邻日期预取、`AbortController` 请求取消与日期/序号双重陈旧响应防护，新增 `scripts/test_frontend_loading.js` 与 `tests/test_frontend_loading.py`。
  - 移除 `static/index.html` 末尾多余的 `</script>` 闭合标签，并在 `scripts/check_inline_js.js` 中增加 `<script>` 标签配对检查。
- **采集稳定性与接口细节**
  - 后台静默启动模式下对端口冲突增加有界重试（6 次 × 30 秒），避免短暂端口占用造成长时间采集断档（`main.py`）。
  - 为 `WindowMonitor` 与 `SystemStateMonitor` 看门狗循环增加异常隔离与 `degraded` 状态留痕，防止单次瞬时异常中断采集（`monitor.py`）。
  - `/api/app-analysis` 支持并校验 `date` 参数；`EmailReports` 改用只读 `DB.path` 属性；基准脚本固定 UTF-8 标准输出。
  - 收录使用指南、隐私安全缺陷报告指南与结构化 GitHub Issue 模板。
